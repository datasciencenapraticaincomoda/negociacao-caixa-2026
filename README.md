# Análise Financeira, Produtividade e Remuneração — CAIXA (2003–2025)

## 📌 Sobre o Projeto
Este repositório contém um estudo independente compilando dados contábeis oficiais, séries históricas, visualizações gráficas e scripts em Python sobre o desempenho financeiro, evolução remuneratória, produtividade e métricas de capital da **Caixa Econômica Federal (CAIXA)**, cobrindo o período de 2003 a 2025.

O objetivo deste projeto é estritamente **analítico, acadêmico, informativo e de utilidade pública**, visando fundamentar debates, pesquisas econômicas e análises setoriais com base em dados contábeis abertos.
